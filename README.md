# 🏰 Castle Builder (성채 빌더)

> **"바이브 코딩(Vibe Coding)의 무분별한 요구사항으로 인한 시스템 붕괴를 막는 시각적 아키텍처 감리 에이전트"**

`Castle Builder`는 복잡한 소프트웨어 공학의 의존성과 기술 부채를 물리적 건축물인 **'성(Castle)'**의 구조 역학으로 1:1 치환하여 직관적으로 조망하고 감리하는 초경량 에이전트 스킬(Skill)입니다.

---

## 🏛️ 4대 아키텍처 계층 매핑

| 계층 | 성(Castle) 메타포 | 소프트웨어 실체 | 위험 신호 |
| :--- | :--- | :--- | :--- |
| **B1** | **지하 암반 및 기초 (Foundation)** | DB 스키마, ORM, 인프라, 코어 데몬 | 지반 침하, 스키마 붕괴 |
| **1F** | **외벽 및 성문 (Walls & Gates)** | API 게이트웨이, 인증/인가(Auth), 미들웨어 | 문 열린 성, 외부 침입 위험 |
| **2F** | **본관 내성 (Keep Main Hall)** | 비즈니스 로직, 핵심 도메인 처리 엔진 | 내력벽 균열, 연쇄 붕괴 |
| **3F** | **상층 망루 (Watchtowers)** | 프론트엔드 UI, 대시보드 컴포넌트 | 공중 부양(기초 결여), 흔들림 |

---

## ⚡ 핵심 기능

1. **0.1초 로컬 프로젝트 엑스레이 (`scanner.py`)**
   - 외부 의존성 설치 없는 초경량 순수 파이썬 스크립트.
   - 프로젝트 파일 트리를 순식간에 분석하여 4대 계층 요약본(`castle_summary.json`) 생성.
2. **초경량 토큰 소모 구조**
   - 수만 줄의 소스코드를 LLM에 직접 전송하지 않고 가벼운 메타데이터 요약본만 전달하여 토큰 비용을 90% 이상 절감.
3. **직관적인 붕괴 경고 & 의사결정 게이트 (Decision Gate)**
   - 기초 없이 UI를 요구하거나 내력벽(DB)을 무너뜨리는 위험 지시 감지 시 공사 중단 후 선택지 제시:
     - `[1] 임시 비계 받치기` (빠른 진행, 균열 경고 유지)
     - `[2] 기초 리팩토링 후 증축` (권장)
     - `[3] 강행` (붕괴 위험 감수)
4. **인터랙티브 단일 파일 뷰어 (`viewer.html`)**
   - 별도 서버 세팅 없이 브라우저에서 바로 열리는 SVG 캔버스.
   - 블록 클릭 인스펙터(상태 진단) 및 상시 구조 안정도(HUD %) 계측기 탑재.
